# GitHub Pages kurulumu

1. GitHub'da `indirim-koparan-app` adlı **Public** depo oluştur.
2. Bu ZIP içindeki dosya ve `assets` klasörünü deponun köküne yükle.
3. **Settings → Pages** bölümüne gir.
4. **Source: Deploy from a branch**, **Branch: main**, klasör: **/(root)** seç ve kaydet.
5. Birkaç dakika sonra adres `https://KULLANICI_ADI.github.io/indirim-koparan-app/` olur.
